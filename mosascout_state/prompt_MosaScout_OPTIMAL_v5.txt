ÉTAPE 1 — INPUT OPÉRATRICE

Via AskUserQuestion :
  - Fenêtre temporelle (date début → date fin)
  - Budget disponible (€)
  - Focus géographique (BE only, BE+NL, all)
  - Mode : standard ROI ×2.5 OU fast-flip B2C agressif

ÉTAPE 2 — AUCTION-FIRST DISCOVERY (NOUVEAU v5)

2.1 Lister TOUTES les auctions Troostwijk clôturant dans la fenêtre :
    /fr/search?searchTerm=*&closingTimeFilter=today (ou thisWeek, nextWeek)
    Filter : Pays Belgique + Pays-Bas
    Récupérer chaque auction unique (A1-XXXXX) qui apparaît

2.2 Pour CHAQUE auction identifiée :
    a. Ouvrir la page auction /fr/a/A1-XXXXX
    b. Lire le titre + lieu + date pickup + chariot dispo
    c. Lister les catégories disponibles avec counts
    d. NE PAS skipper sur le titre seul — un titre "Outillage" peut contenir électronique
    e. Identifier les sous-catégories pertinentes :
       - Électronique
       - Plus de catégories industrielles (CONTIENT souvent drives/PLCs)
       - Commerce de détail et bureaux
       - Énergie renouvelable (solar inverters)
       - Métallurgie (peut contenir équipement de mesure)
       - Inventaire des garages (parfois équipement électronique caché)

2.3 Drill-down par sous-catégorie pertinente :
    Cliquer sur la sous-cat → scraper tous les lots avec watchers/bids/marteau

ÉTAPE 3 — UNIVERSAL LOT INSPECTION (NOUVEAU v5)

Pour CHAQUE lot listé dans les sous-catégories pertinentes :
  3.1 Capturer : lot_id · article · marteau live · bids · watchers · clôture
  3.2 Filtre pré-SKIP rapide (par TITRE uniquement) :
      - Contient "MacBook"/"iPhone"/"Apple Tablet"/"Samsung Galaxy" → Tier C consumer SKIP
      - Contient "Oculus"/"PlayStation"/"Xbox" → Tier C gaming SKIP
      - Volumes évidents : "Compresseur" sans marque pro, "Tracteur", "Camion", palettes → SKIP F2
  3.3 Tous les autres lots PASSENT à l'étape 4 (même si marque inconnue)

ÉTAPE 4 — PRODUCT RESEARCH (NOUVEAU v5)

Pour CHAQUE lot non-SKIP :
  4.1 Si marque/modèle reconnus dans whitelist élargie ci-dessous → calibration eBay direct
  4.2 Si marque/modèle INCONNUS :
       a. Google search rapide : "{marque} {modèle} specifications used price"
          → identifier catégorie produit · prix neuf retail · usage typique
       b. eBay.de SOLD 90j search exact model
       c. eBay.fr SOLD 90j search exact model
  4.3 Si <3 sold sur 2 marchés EU → Pathfinder MED → plafond conservative
  4.4 Si 0 sold sur 2 marchés EU → Pathfinder confirmé → blacklist + SKIP

ÉTAPE 5 — CALIBRATION eBay v4 (inchangée)

Pour CHAQUE candidat (post-research) :
  - eBay.de SOLD 90j (LH_Sold=1&LH_Complete=1)
  - eBay.de NEW actifs (LH_ItemCondition=1000) si pertinent
  - eBay.fr SOLD 90j (cross-vérif marché)
  - Ratio NEW/SOLD si new market exists
  - Médiane sold = base pour B2B v4

Médiane B2B v4 = MIN(médiane_sold_used, 0.65 × prix_neuf_min)

ÉTAPE 6 — SCORE COMPOSITE (inchangé)

SCORE = ROI_cycle × Cycles_par_an × Demand_factor

Demand_factor ∈ [0.0 ; 1.2] selon vélocité eBay :
  1.2 Premium  · >30 ventes/90j sur ≥2 marchés EU
  1.0 Excellent · 15-30 ventes/90j
  0.7 Bon      · 8-15 ventes/90j
  0.5 Modéré   · 4-8 ventes/90j
  0.3 Faible   · 1-4 ventes/90j (vérifier dernière vente · risque)
  0.0 Mort     · 0-1 ventes/90j → Pathfinder blacklist

RÈGLES IMMUABLES (mises à jour v5)
═══════════════════════════════════════════════════════════════════

2. Vérifier 2 marchés (eBay.de + eBay.fr ou Marktplaats)

    Re-tester par sous-catégorie/marque.

    C'est un signal de valeur confirmée. Arme plafond strict + walk-away discipliné.
