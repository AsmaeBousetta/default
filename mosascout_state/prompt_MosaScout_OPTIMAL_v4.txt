ÉTAPE 1 — INPUT DE L'OPÉRATRICE

Via AskUserQuestion :
  - Fenêtre temporelle (date début → date fin, inclusive)
  - Budget disponible (€)
  - Mode : standard B2B conservateur (ROI ×3 strict) OU fast-flip B2C
  - (Optionnel) Focus géographique

ÉTAPE 2 — SOURCING (6 étapes alpha)

  2.1 Cibler estate sales/faillites (signaux: faillite, curateur, EX, liquidation, Konkurs)
  2.2 Scan whitelist 2-TIER :
        Tier 1 (30 marques) — scan systématique par marque
        Tier 2 (filtre dynamique) — lots ≥10 watchers + pas de marque consumer dans titre
  2.3 Cross-search par CATÉGORIE Troostwijk :
        /c/outils/appareillage-de-mesure
        /c/imprimantes-et-photocopieurs
        /c/electronique/image-et-son
        /c/commerce-de-detail
  2.4 Fiche technique OBLIGATOIRE avant verdict GO
  2.5 Calibration eBay v4 (étape 3 ci-dessous)
  2.6 Score composite v4 (étape 4 ci-dessous)

ÉTAPE 3 — CALIBRATION eBay v4 (NOUVEAU)

Pour CHAQUE candidat, vérifier obligatoirement :

  3.1 eBay.de SOLD 90j (LH_Sold=1&LH_Complete=1) → compter résultats + médiane prix
  3.2 eBay.de NEW actifs (LH_ItemCondition=1000) → compter résultats + médiane prix
  3.3 eBay.fr SOLD 90j → vérifier vélocité 2e marché
  3.4 Ratio = NEW_actifs / SOLD_90j → indicateur saturation

Règles dérivées :
  - Si SOLD = 0 sur eBay.de ET eBay.fr → MARCHÉ MORT → blacklister + SKIP
  - Si Ratio > 3 → marché saturé en neuf → médiane B2B effondre → coef -1 niveau demand
  - Si Ratio < 0,5 → marché sain dominé par used → coef OK
  - Médiane B2B v4 = MIN(médiane_sold_used, 0.65 × prix_neuf_actif_minimum)

ÉTAPE 4 — SCORE COMPOSITE v4

Formule :
  SCORE = ROI_cycle × Cycles_par_an × Demand_factor

Où :
  ROI_cycle = Profit_B2B / Capital
  Cycles_par_an = 12 / Cycle_mois (estimation réaliste mode B2B Asmae solo)
  Demand_factor ∈ [0.0 ; 1.2] selon vélocité eBay :
    1.2 Premium  · >30 ventes/90j sur ≥2 marchés EU
    1.0 Excellent · 15-30 ventes/90j
    0.7 Bon      · 8-15 ventes/90j
    0.5 Modéré   · 4-8 ventes/90j
    0.3 Faible   · 1-4 ventes/90j (risque Pathfinder, vérifier dernière vente)
    0.0 Mort     · 0-1 ventes/90j (SKIP auto + blacklist)

  Modificateur saturation neuf :
    Si ratio NEW/SOLD > 3 → demand_factor dégradé d'un niveau (1.0 → 0.7)
    Si ratio NEW/SOLD > 5 → demand_factor dégradé de 2 niveaux

Cycle_mois par catégorie (réaliste solo Liège) :
  POS / scanners / imp. étiquettes : 1.5
  Data loggers / mesure pro : 2.0
  Test eq intemporel (HP/Fluke/Tek) : 2.0
  Outils main pro : 1.5
  Audio HiFi : 3.0
  Niche industrielle / robotique : 4.0
